Podcast Management Module for Odoo 18

Easily manage podcasts, channels, and episodes in Odoo 18 with full support for audio files, metadata, and seamless Shenoto integration.

Live Demo

See the module in action:
Demo URL: https://sazmanyar.tashilgostar.com/podcasts

Key Features

  • Podcast Channel Management – Create and organize channels with cover images, descriptions, and categories.
  • Episode Management – Upload audio files or add external links (e.g., Shenoto) with metadata tracking (duration, release date, tags).
  • Shenoto Integration – Import episodes directly from Shenoto via URL.
  • Website Ready – Fully compatible with website_podcast for frontend display.
  • Security & Access Control – Custom permissions for podcast managers.
