Frequently Asked Questions

Can I import podcasts from platforms other than Shenoto?
Currently, the module has specialized integration for Shenoto. You can manually add episodes from other platforms by uploading audio files and entering metadata.
Is this module compatible with older versions of Odoo?
This module is specifically designed for Odoo 18.0. For older versions, please contact us for compatibility information.
Can I use this module for video podcasts?
The module is primarily designed for audio podcasts. For video content, we recommend our Aparat module or the built-in Odoo video capabilities.
