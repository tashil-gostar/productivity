# Odoo Productivity Modules Collection

![Odoo Version](https://img.shields.io/badge/Odoo-18.0-purple)
![License](https://img.shields.io/badge/License-AGPL--3-green)

A suite of productivity-enhancing modules for Odoo 18, specifically designed with Iranian users in mind to overcome international sanctions and service limitations.

**Live Demo:** [View Demo](https://sazmanyar.tashilgostar.com)  
**Documentation:** [Technical Docs](https://www.tashilgostar.com/documentation/18.0/)  

---

## ✨ Key Features

- **Sanction-proof solutions**: Local alternatives to restricted international services
- **Standalone functionality**: Modules work independently with optional integrations
- **Persian language support**: Fully localized UI and documentation
- **API-ready**: Configurable connections to local services

---

## 📦 Available Modules

| Module  | Description | Special Requirements |
|---------|-------------|----------------------|
| Podcast | Manage podcast channels and episodes | Shenoto API (optional) |
| Aparat  | Aparat compatibility with odoo |  |

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/tashil-gostar/productivity.git ./addons/

# Install specific module
odoo-bin -i module_name --database your_db
```
