Aparat Integration Module for Odoo 18

This module provides seamless integration between Aparat (Iranian video-sharing platform) and Odoo 18, enabling video management and embedding capabilities.

Live Demo

Experience the module in action:
Demo URL: https://sazmanyar.tashilgostar.com/podcasts

Key Features

  • Video Embedding - Embed Aparat videos anywhere in Odoo (Blogs, Products, etc.) with responsive iframe support and custom styling
  • Media Dialog Integration - Special Aparat tab in Odoo's media dialog to search and select videos directly from Aparat
  • HTML Editor Compatibility - Works seamlessly with Odoo's html_editor module
  • Enterprise Ready - Designed for enterprise clients with auto-installation for easy deployment
  • Custom Styling - Dedicated SCSS files for perfect visual integration

Installation

  1. Install the module through Odoo Apps
  2. The module will auto-install required dependencies (html_editor)
