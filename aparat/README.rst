This module provides seamless integration between **Aparat** (Iranian video-sharing platform) and **Odoo 18**, enabling video management and embedding capabilities.

------------
Live Demo
------------

Experience the module in action:
**Demo URL:** https://www.tashilgostar.com/slides/slide/149/share

------------
Features
------------

✅ **Video Embedding**
   - Embed Aparat videos anywhere in Odoo (Blogs, Products, etc.)
   - Responsive iframe support with custom styling

✅ **Media Dialog Integration**
   - Special Aparat tab in Odoo's media dialog
   - Search and select videos directly from Aparat

✅ **HTML Editor Compatibility**
   - Works seamlessly with Odoo's ``html_editor`` module

✅ **Enterprise Ready**
   - Designed for Tashilgostar's enterprise clients
   - Auto-installs for easy deployment

✅ **Custom Styling**
   - Dedicated SCSS files for perfect visual integration

------------
Installation
------------

1. Install the module through Odoo Apps
2. The module will auto-install required dependencies (``html_editor``)
